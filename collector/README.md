# 로컬 치지직 수집기

이 수집기는 `127.0.0.1:3211`에서만 동작합니다. 치지직 채널 ID를 연결하면 공개 채팅 웹소켓 이벤트를 받고, 일반 채팅·후원·공지·블라인드 이벤트를 정규화합니다. 라이브러리가 아직 별도 이름을 붙이지 않은 미션/파티 및 미래 이벤트는 원본 프레임까지 보관해 대시보드의 `파티·미션` 또는 `기타 원본`에 표시합니다.

## 실행 순서

1. 프로젝트 최상단의 `start-chzzk-dashboard.bat`을 실행합니다. 수집기와 대시보드가 함께 시작되고 브라우저가 열립니다.
2. 브라우저로 `http://localhost:3000`을 열고 채널 ID를 입력해 수집을 시작합니다.
4. 마인크래프트 플러그인을 켠 뒤 대시보드의 **마인크래프트 전달**에서 플러그인 주소와 `api-token`을 입력하고 전달을 활성화합니다.

대시보드에 입력하는 플러그인 토큰은 수집기 메모리에만 남습니다. 수집기를 종료하면 사라집니다.

## 이벤트 처리 원칙

- `채팅`, `일반 후원`, `공지`, `블라인드`는 라이브러리 이벤트로 표시합니다.
- `파티·미션`은 원본 이벤트의 `MISSION` 또는 `PARTY` 표기를 탐지해 분류합니다.
- 알 수 없는 원본 프레임도 버리지 않고 화면에서 JSON으로 확인할 수 있습니다. 치지직의 내부 형식이 바뀐 경우 이 원본을 기준으로 분류기를 보완할 수 있습니다.
- 마인크래프트에는 금액이 확정된 `일반 후원`만 전송합니다. 파티/미션은 상태 변화·성공 여부의 의미가 다를 수 있어 자동 명령 실행 대상에서 제외했습니다.
